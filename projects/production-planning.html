Galaxy Watch Production Planning

A production management project translating demand forecasts into supply planning, inventory decisions and production schedules.

Holt-Winters Forecasting MPS MRP Inventory management

Project snapshot

Goal Turn demand data into a production plan
Method Forecasting, capacity planning, MPS, MRP and EOQ
Focus Connecting market demand to operational decisions

Overview

Why I did this

Engineering is not only about designing products, but also about understanding how they can be produced, supplied and delivered reliably. This project connected technical product thinking with operations and planning.

Method

How it was planned

Demand was forecasted using time-series methods. The forecast was then used to develop production planning, material planning and inventory decisions for the Galaxy Watch 8.

Results

Good planning connects data to decisions.

The project showed how demand forecasts can directly influence production capacity, inventory levels and material requirements. The main result was a structured planning framework instead of only a single forecast.

Takeaway

What this shows

A useful forecast only becomes valuable when it supports decisions. This project helped me understand how engineering, production and supply-chain planning are connected in real companies.

Tools

Skills used

Forecasting, data cleaning, Holt-Winters modelling, capacity planning, master production scheduling, material requirements planning and inventory analysis.
